A program that writes exactly one letter — `A` for coffee — to `/output/entry.txt` for make.fun's "One Letter: Coffee or Tea" bounty. The brief allows nothing else: no word, no explanation, no punctuation, and the gate requires exactly 1 UTF-8 character. The choice is coffee: the dark, bitter, morning-fire drink with the ritual, the steam, and the first-sip jolt — the vivid one against tea's gentle patience. It runs offline, reads nothing from the network, and writes the same letter on every run.

## Run it

```sh
python3 main.py
```
